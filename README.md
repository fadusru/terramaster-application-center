# Центр приложений Terramaster

В Центре Приложений Terramaster появилось много приложений. Совершается попытка систематизировать информацию о 
назначении, настройке и др. особенностях приложений.

В режиме "Pages" данный репозиторий можно запустить на ресурсе: [fadusru.github.io/terramaster-application-cente](https://fadusru.github.io/terramaster-application-center/)

Демонстрация материалов подготовлена для рендеринга в Docsify. Инструкцию по установке и настройке Docsify в одноименном 
репозитории в данном аккаунте, она же на https://fadusru.github.io/docsify/.
